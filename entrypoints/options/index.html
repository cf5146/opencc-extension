OpenCC settings

Choose when pages convert automatically. Set the global language pair in the popup.

Default policy

Automatic conversion uses the source and target selected in the popup. The page-language safeguard skips pages explicitly marked with a non-Chinese language.

Site rules

Use the popup on a site to choose Always, Never, or Use default. Rules apply to the exact hostname. Excluded URL patterns still apply.

    Advanced exclusions

    One JavaScript regular expression per line, matched against the full URL. These are regular expressions, not wildcard patterns. Existing patterns are shown exactly as saved. Invalid expressions cannot be saved.
